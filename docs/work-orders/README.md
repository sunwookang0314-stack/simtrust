# 폼 B v2 기준 작업 문서

정답지 수집을 기능별 사용 경험 설문(폼 B v2)으로 바꾸면서 나온 문서다.

| 폴더 | 내용 |
|---|---|
| `docs/form-b/` | 폼 B v2 초안과 구글폼 생성 스크립트(Apps Script) |
| `docs/work-orders/kim-minwoo/` | AI 제시 프로토콜, v0.1 참고 초안, AI 실행기 |
| `docs/work-orders/yang-jeongwoo/` | TRD·PRD·WBS 수정 정리와 작업지시서 |

- 문서 안의 `자료함/설문/`은 `docs/form-b/`, `자료함/작업지시/김민우/`는 `docs/work-orders/kim-minwoo/`, `자료함/작업지시/양정우/`는 `docs/work-orders/yang-jeongwoo/`다
- 화면 캡처와 설문 응답 원문은 비공개라 저장소에 없다(TRD SEC-12). 문서에 나오는 `자료함/캡처-비공개/` 경로와 캡처 폴더는 팀 안에서만 주고받는다
