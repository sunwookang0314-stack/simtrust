## 3. 화면 입력 방식
- 자동 영어 요약: 끔 [정함]
  - 실행기 설정 `auto_image_description: false`로 `_describe_images`를 막는다
  - 오프라인 테스트와 11/5 Gemini 호출에서 요약 요청이 0번이었다
- 이전 화면 다시 보여주기 수: 1 [정함]. 0은 실행기가 막는다
- see() 묶는 방법: 서비스 캡처 전부를 `see()` 한 번으로 [제안, 1번 ①을 따름]
  - 오프라인 테스트에서 캡처 3장을 한 번에 주면 질문 4개 요청마다 3장씩 들어갔다. 중복은 없었다
- 캡처 없는 기능 처리: 묻지 않고 원시 응답에 `skipped: 없음`으로 남긴다 [제안]. 실행기는 스냅샷의 `missing_features`로 처리한다
- 캡처 파일 이름 규칙: 무작위 16진수 8자리 + `.png` [제안]. 원래 이름과의 대응표는 private/에 둔다. data URI는 쓰지 않는다 [정함]
  - 캡처 경로가 요청마다 글자로 모델 입력에 들어간다. 가짜 화면으로 확인해 보니 `images/fake/app/S1.png`가 질문 4개 요청에 모두 들어 있었다
  - 그래서 파일 이름뿐 아니라 폴더 이름에도 기능 이름이나 세트 이름을 쓰지 않는다. 실행기는 PC 경로 대신 리포 기준 상대 경로를 넘긴다
  - 실행기 설정 `require_random_capture_names: true`로 켜면 규칙에 안 맞는 이름에서 멈춘다
- 1단계 가짜 화면 확인 (`scripts/check_image_input.py`)
  - 요청당 이미지 장수: 3장 묶음을 주면 3장 [확인]
  - 화면 글자를 맞게 말했는지: 이미지 __ / 텍스트 __ [측정 대기]. Gemini가 503과 429를 계속 줘서 답을 아직 못 받았다
- 고른 것 (3단계): 이미지 / 텍스트 [측정 대기]
- 이유 (실측 숫자): [측정 대기]

## 4. 캡처로 안 드러나는 기능 (강선우가 정한 내용)
- 웹/앱: 두 플랫폼을 다 쓴다. 가상 사용자 한 명한테는 한 플랫폼 화면만 준다 [정함]
- 계정: 기존 계정이고, 예전 기록(대외활동 스크랩, 채널 팔로우)은 11/1에 지웠다 [정함]
  - 참고 초안 4번에는 "서비스마다 새 계정"으로 적혀 있다. 실제로는 기존 계정을 정리해서 찍었다
- 마감 알림 [정함]
  - 앱 플랫폼: 링커리어 "스크랩 공고 알림: 마감일 D-1일 때 알림" 설정과 알림이 온 알림함, 캠퍼스픽 "마감 임박 알림: 마감 D-3 알림" 설정과 알림함
  - 웹 플랫폼: 링커리어는 알림이 온 웹 알림함·스크랩 달력·앱 설치 배너. 캠퍼스픽은 웹에 알림 페이지가 없어서 마감임박순 정렬 화면으로 대신한다
- 추천 공고 목록: 두 플랫폼 모두 인기·추천 목록. 개인 맞춤 추천은 두 서비스 모두 안 보였다 [정함]
- 검색어 세트: 인턴 세트 (11/3 정함) [정함]
- 없는 기능: 11/2 캡처 기준으로 두 플랫폼 모두 해당 없음 [정함]
- 한계로 적는 것
  - 앱 캡처는 안드로이드라 아이폰 앱과 메뉴 위치가 다를 수 있다
  - 웹 플랫폼의 캠퍼스픽 마감 알림 칸은 기능 자체가 아니라 가장 가까운 화면이다

## 6. 에피소드
- 서비스·플랫폼당 한 에피소드, 에피소드마다 새 에이전트 [정함]. 두 번째 에피소드에 첫 번째 기억이 안 들어가는 것을 테스트로 확인했다
- 질문 순서: (b) [결정 대기, 강선우]. 실행기는 (b)만 짜 두었다
  1. 시작 안내
  2. 섹션 안내 + 캡처
  3. Q-AI-USE: 기능마다 쓸 것 같다 / 안 쓸 것 같다
  4. Q-AI-WHY-USE: 쓸 것 같다고 한 기능의 이유
  5. Q-AI-NOUSE: 안 쓸 것 같다고 한 기능의 4-6 보기
  6. Q-4-7: 폼 4-7 문항 그대로
  - 쓸 것 같은 기능이 없으면 4를, 안 쓸 것 같은 기능이 없으면 5를 건너뛴다. 실행기가 Q-AI-USE 답에서 어느 기능 답인지 못 가리면 4와 5를 다 묻는다
- 기능 순서: 4-3 행 순서 그대로 [정함]
- 기능 목록·질문 파일 위치: `docs/ai-protocol/features.txt`, `docs/ai-protocol/options_4-6.txt`, `docs/ai-protocol/questions/{질문 ID}.txt` [제안]
  - 지금은 개발용 사본이 `experiments/runner_dev/protocol/`에 있다. v0.1을 확정하면 이 위치로 옮기고 실행 설정 `protocol_dir`를 바꾼다
