# 조건 3 후기 자료 출처 조사

- 작성: 김민우, 2026-11-05 (#11)
- 조사만 했다. 무엇을 쓸지는 팀이 정한다
- 웹 검색으로 확인한 범위다. 약관 원문을 다 읽은 것은 아니라서 "못 찾았다"와 "없다"를 구분해 적었다

## 조건 3이 뭔가 (TRD v0.1)

- FR-03-03: "조건 3에서는 대외활동 후기 검색 결과를 페르소나 배경에 붙일 수 있어야 한다. 테스트 대상 서비스 이름이 들어간 자료는 제외해야 한다."
- 미결정 표: "조건 3 후기 자료의 출처 (공식 API가 있는 곳만)", 담당 김민우
- 시스템 경계: 대상 서비스에 자동으로 접속하거나 데이터를 긁어오지 않는다. 후기 검색 인덱스는 FAISS로 만든다
- AI실행기.md: 비용 상한 승인 실측은 입력이 가장 큰 조건 3으로 한 번 받는다

그래서 필요한 출처는 세 가지를 다 만족해야 한다. 공식 API가 있고, 결과를 모아 검색 인덱스로 만들어도 되고, 그 내용을 LLM 입력에 넣어도 되는 곳이다.

## 후보

| 후보 | 공식 API | 걸리는 점 | 판단 |
|---|---|---|---|
| 네이버 검색 API (블로그) | 있음. 하루 25,000회로 안내됨 | 네이버 클라우드 가이드는 결과를 받은 즉시 한 번 쓰는 것만 허용하고 저장, DB화, 재사용을 금지한다. 개정 약관은 AI 학습과 답변 생성에 쓰는 것을 제한하고 출처와 원본 링크 표시를 요구한다(보도 기준). FAISS 인덱스는 저장·DB화에, 페르소나 배경으로 LLM에 넣는 것은 답변 생성 활용에 걸린다 | 쓰기 어렵다 |
| 다음(카카오) 검색 API (블로그) | 있음 | 개발자 포럼 담당자 답변으로 AI 학습 활용을 허용하지 않고, 검색 결과를 외부 LLM API로 보내는 것도 제한된다고 한다(2차 정보). 쿼터 상향도 현재는 안 해 준다고 한다 | 쓰기 어렵다 |
| YouTube Data API (영상 설명, 댓글) | 있음 | 대부분의 API 데이터는 30일 넘게 저장하지 못하고 갱신하거나 지워야 한다. API 데이터로 새 지표를 만드는 것도 금지다. AI 사용을 직접 막는 조항은 2차 자료 기준으로 못 찾았다. 캐시로 재현하는 반복 실험과 30일 규칙이 부딪힐 수 있다 | 조건부. 약관 원문 확인 필요 |
| AI Hub 공개 데이터 | 신청해서 내려받음 | 대외활동 후기 데이터셋은 못 찾았다. 데이터셋마다 이용 조건이 다르다 | 맞는 데이터를 못 찾음 |
| 테스트 대상 서비스(링커리어, 캠퍼스픽)의 활동 후기 | 공식 API를 못 찾음 | 크롤링을 안 하기로 했고, 서비스 이름이 든 자료는 빼야 한다 | 제외 |
| 폼 응답 | 해당 없음 | 정답지라서 넣으면 답을 미리 보여주는 셈이다. 폼에서 외부 AI 서비스에 보내지 않는다고 약속했다 | 제외 |

## 정리

TRD 조건(공식 API, 크롤링 없음)과 두 국내 검색 API의 약관(저장 금지, AI 활용 제한)을 같이 지키면서 후기 검색 인덱스를 만들 수 있는 출처는 이번 조사 범위에서 못 찾았다.

팀이 고를 선택지 [AI 제안]

1. 조건 3을 이번 학기 범위에서 빼고 한계와 다음 단계로 적는다. 비용 상한 승인은 조건 2 실측으로 받고, 나중에 조건 3을 붙이면 다시 승인받는다
2. YouTube Data API로 바꾸고, 30일 안에 실험과 분석을 끝내는 조건으로 쓴다. 쓰기 전에 Developer Policies 원문을 확인한다
3. 후기 대신 팀이 쓸 수 있는 다른 배경 자료로 바꾼다. 이 경우 "후기 검색"이 아니어서 FR-03-03 문장을 고쳐야 한다

범위를 줄여 끝까지 한 바퀴 도는 게 우선이라면 1이 가장 현실적이다. 조건 0·1·2만으로도 "페르소나를 얼마나 줘야 믿을 만해지나"는 잴 수 있다.
