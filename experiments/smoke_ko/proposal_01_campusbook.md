# 서비스 기획안: 「캠퍼스북」 — 우리 학교 전용 중고 교재 거래 앱

## 1. 한 줄 소개
같은 학교 학생끼리 전공 교재를 사고파는 모바일 앱. 학교 인증을 거친 학생만 이용할 수 있어 안전하다.

## 2. 대상 사용자
- 학기 초에 교재를 싸게 구하고 싶은 대학생
- 학기 말에 다 쓴 교재를 처분하고 싶은 대학생

## 3. 가입 절차
1. 앱 설치 후 휴대폰 번호로 본인 인증 (SMS 인증번호 입력)
2. 학교 이메일(@hansung.ac.kr)로 재학생 인증 (인증 메일 클릭)
3. 학생증 사진 업로드 (관리자가 24시간 이내 승인)
4. 프로필 작성: 실명, 학과, 학번, 프로필 사진(필수)
5. 서비스 이용약관·개인정보 처리방침·마케팅 정보 수신 동의 (모두 필수 체크)
6. 승인 완료 후 이용 가능

## 4. 핵심 기능
- **교재 등록**: 책 사진 3장 이상 촬영 → ISBN 자동 인식 → 상태(상/중/하) 선택 → 희망 가격 입력
- **검색·탐색**: 과목명, 교수명, 학과별로 검색. 이번 학기 개설 과목 목록과 연동
- **채팅**: 앱 내 1:1 채팅. 거래 약속 장소는 교내 정문·도서관·학생회관 중에서 선택
- **결제**: 판매자 계좌로 직접 계좌이체. 앱은 결제를 중개하지 않음
- **거래 후기**: 거래 완료 후 서로 별점(1~5) 평가. 별점 3 이하를 3회 받으면 계정 정지
- **알림**: 관심 과목 교재가 등록되면 푸시 알림 (기본값: 켜짐, 밤 11시~아침 7시에도 발송)

## 5. 수익 모델
- 판매 등록 시 건당 500원 등록 수수료 (판매자 부담)
- 상단 노출 광고 (건당 2,000원)

## 6. 화면 흐름 (요약)
스플래시 → 온보딩 3장 → 가입(6단계) → 홈(추천 교재 목록) → 검색 → 상세 → 채팅 → 거래 완료 → 후기

## 7. 출시 계획
- 베타: 한성대학교 재학생 대상
- 정식 출시: 서울 소재 대학 10곳 순차 확대
