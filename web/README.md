## 실행
```
cd web
```

## 화면 (11/21 개편)
위쪽 메뉴는 **한눈에**, **시연**, **결과 지도** 셋이다 (한눈에는 11/25 추가). 옛 화면 1~5는 시연 한 페이지로 합쳤고, 새 MVP 점검(학기 범위 밖)은 뺐다. 옛 주소(`#/ask` 등)는 `#/demo`로 넘어간다.

| 주소 | 화면 |
|---|---|
| `#/` | 메인 (묻기 → 견주기 → 알려주기 그림 세 칸) |
| `#/quick` | 발표용 한눈에 보기. 과정 없이 질문 → 결과. `+ 캡처 올리기`(직접 파일, 기능은 파일 이름으로: 검색·필터 / 저장·스크랩·찜 / 알림·마감 / 추천·인기) 또는 예시 캡처를 올리면 화면을 읽는 척하며 기능을 자동으로 정하고(실제 인식 없음), "○○ 기능, 사람들이 쓸까?" 를 AI 하나에게 물으면. 예시 데이터일 때만(`IS_SAMPLE`) 가상 대학생 AI를 가장 좋게 보여 주는 시연 시나리오(`viewOf`), 실제 결과로 바뀌면 계산기 결과 그대로. 신호등(초록·노랑·빨강)과 AI·사람 이유가 겹치는 원 그림. 본 판정 칸(안 쓸 이유)을 동결 규칙(`rules.v1.json`, fixed_70)으로 계산(`verdictV1`). 위쪽 메뉴 없이 꽉 찬 화면, Enter·→ 물어보기, ← 처음으로 |
| `#/demo` | 시연 한 페이지. 기능 하나(기본 마감 알림, 1장 토글로 바꿈) · 쓸 이유 칸을 GPT로 따라간다 |
| `#/map?kind=` | 결과 지도 (기능 4개 × AI 넷). 칸을 누르면 시연 3장 거름망으로 |

### 시연 한 페이지
`다음` 버튼(또는 → 키·스페이스, 뒤로는 ←) 한 번이 박자 하나다. 장이 바뀌면 그 장으로 스크롤한다.

| 장 | 박자 | 장면 |
|---|---|---|
| 0 시작 | 0~1 | 오프닝 질문. GPT에게 120번 물은 답이 깔리고 숫자가 오른 뒤, 가장 많이 나온 말을 인용 → "이 말, 믿고 서비스를 만들어도 될까요?" |
| 1 묻기 | 2~3 | 마감 알림 화면과 질문 → GPT 답이 한 글자씩. 위 토글로 기능·서비스·앱/웹을 바꾼다. 기능을 바꾸면 오프닝부터 거름망까지 그 기능 이야기로 바뀐다. 끝에 "AI 4개 답 전체 보기" |
| 2 칩 만들기 | 4~8 | 형광펜 → 떼어 냄 → 이름표(같은 뜻 합치기) → 다른 답도 → 답 120개에서 칩 알갱이가 쏟아져 이름표로 날아가고 숫자가 오르며 칩이 커짐. 끝에 "뽑은 이유 전체 보기"(이름표 묶음, 판정자 기록 표) |
| 3 거름망 | 9~13 | 칩이 대학생 구멍을 통과 → 걸림 → 놓친 이유 → 판정 도장(판정은 도장으로만 공개). 여기서 Claude·Gemini·페르소나 AI로 바꿔 본다 |
| 4 결과 | 14 | AI 넷 카드(판정, 왜, 두 비율). 다른 칸 고르기, 결과 지도로 |

주소: `?beat=N`(발표 연습용, 그 박자부터), `?go=장 id`(hook·ask·chip·sieve·result, 그 장부터), `?feature=&kind=&ai=`(3장 칸과 AI), `?service=&platform=`(1장 화면), `?base=`(페르소나 바탕 모델).
2장 칩 자리는 3장 거름망 AI 영역과 같은 좌표(`src/lib/stage.js`)라서, 칩이 그대로 거름망으로 넘어가는 것처럼 보인다.

## 화면 글 원칙 (11/21)
- 처음 10분 보는 사람 기준. 장면마다 제목 한 줄 + 설명 한 문장
- 팀 안 용어(조건 0, Q-AI-*, kappa, fixed_70 등)는 화면에 쓰지 않는다. 필요하면 접는 설명(`More`)이나 파일 주석에
- "가짜 견본·예시" 표시는 위쪽 바의 `예시 데이터` 하나로

## 데이터
- `src/lib/story.js`: 기능 4개마다 시연이 따라가는 GPT 답 셋·이유 조각·오프닝 인용 (지어낸 것, 쓸 이유. 이름표는 코드북·견본에 있는 것만)
- `src/lib/examples.js`: 접어 둔 "답 전체 보기"의 예시 답·이유 줄·판정자 코드 (지어낸 것)
- `public/data/codebook.csv`: 코드북 v1.0 작업본 (이름표 이름·정의)
- `public/data/sample/`: 판정 계산기(`scripts/score_reasons.py`) 출력 형식의 가짜 견본 (`experiments/demo_sample/out/`, 김민우)
- 실제 결과가 나오면 같은 이름의 `cells_*.csv`, `reasons_*.csv`로 바꾸면 된다. 읽는 코드는 `src/lib/data.js`
- 응답 원문은 넣지 않는다. 계산기 결과(코드와 숫자)만 쓴다

## 구조
- `src/lib/` 데이터 읽기, 판정 색·문장, 장·박자(`steps.js`), 이야기(`story.js`), 무대 좌표(`stage.js`), 움직임 도구(`motion.js`), 주소 파라미터
- `src/components/` 장면(`HookScene`, `AskScene`, `ChipStage`, `SieveStage`), 접는 내용(`AllAnswers`, `ReasonBook`), 캡처(`Shot`), 공용 부품(`ui.jsx`)
- `src/pages/` 메인, 시연, 결과 지도
