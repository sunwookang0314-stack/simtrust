# SimTrust UI 목업 (화면 11개)

앱 화면 11개를 새 디자인으로 그린 HTML 목업입니다. 숫자와 문장은 `app/demo_data.py`의 예시값 그대로이고, 화면 번호와 화면 ID도 TRD와 같습니다. 아직 Streamlit 앱에는 반영하지 않았습니다.

## 바로 보기

- `overview.png`: 11개 화면을 한 장에 모은 비교판
- `shot_화면번호.png`: 화면별 전체 캡처 (1440px 폭)
  - `shot_2-2_detail.png`: 2-2 이슈 카드 상세 상태
  - `shot_4-2_open.png`: 4-2 상세 수치를 펼친 상태
  - `shot_5-1_첫화면.png`: 5-1 발표용 첫 화면 (1440×900)
  - `shot_4-1_1280.png`, `shot_5-1_1280.png`: 노트북 폭(1280) 확인용

## 직접 눌러 보기

1. 이 브랜치를 받거나(`git fetch` 후 `git switch ui-mockup`), GitHub에서 Code → Download ZIP으로 받습니다.
2. `mockup/index.html`을 크롬이나 엣지로 엽니다. 카드를 누르면 화면이 열리고, 상단 메뉴와 다음 버튼으로 화면 사이를 오갈 수 있습니다.

- 글꼴(Pretendard)을 인터넷에서 받아 오니 인터넷이 연결돼 있어야 합니다.
- 폴더 안 파일끼리 서로 불러 쓰니 `index.html` 하나만 따로 옮기면 깨집니다.

## 디자인 규칙

- 뼈대는 토스증권 종목정보 화면, 결론 문장은 토스 애널리스트 의견, 문턱 막대와 고칠 목록은 PageSpeed, 이유 목록은 네이버 플레이스를 참고했습니다.
- 색은 파랑 한 계열과 회색만 씁니다. 파랑은 판정 단계와 AI 조건 0~3에만 씁니다.
- 모든 화면은 첫 패널 맨 위에 데이터로 뒷받침되는 결론 한 문장이 있습니다.
- "경계" 표식과 판정 문턱선은 같은 점선입니다. SimTrust만의 표식이라 다른 뜻으로는 쓰지 않습니다.
- 창업자 화면(4-2 신뢰도 지도, 5-1 점검 결과)에는 조건 번호, 화면 ID 같은 내부 정보를 올리지 않고 바닥의 접힌 "데이터 출처" 안에만 둡니다.

## 아직 안 된 것

- 오류 상태 화면(E1~E11)은 그리지 않았습니다. 데모 상태 선택에서 "(목업 없음)"으로 막혀 있습니다.
- 필터는 목업에 그린 값만 고를 수 있습니다.
- `demo_data.py`의 GD-01이 두 가지 내용으로 쓰입니다. 3-2 허위 지적 근거의 GD-01과 1-2 정답지의 GD-01이 서로 다릅니다. 어느 쪽으로 맞출지 정해야 합니다.
